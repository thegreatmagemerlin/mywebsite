Control Systems Embedded C++ Mechatronics

Overview

This project is a single-axis drone stabilization platform built to learn and implement PID control in a real embedded system.

Using an Arduino, an MPU6050 IMU, and two DC motors, the system measures pitch angle in real time and applies corrective motor output to balance around a target angle. The platform was designed as a simplified drone control system to isolate and understand the core principles behind quadcopter stabilization before moving to a full multi-axis drone.

The project focuses not only on implementing PID mathematically, but also on solving the real-world engineering problems that appear in physical control systems, including electrical noise, actuator dead zones, timing inconsistencies, and integral windup.

The problem

A drone remains stable by continuously correcting its orientation. Even small tilts must be detected and corrected rapidly to prevent instability.

The challenge was to build a system capable of:

  • Accurately measuring pitch angle in real-time
  • Determining how far the system is from the target angle
  • Applying motor corrections smoothly and quickly enough to restore balance

A major difficulty was that real hardware behaves differently from ideal mathematical models. Motors do not respond linearly at low PWM values, sensors contain noise, and timing inconsistencies can destabilize the controller. The project therefore became an exercise in both control theory and practical embedded systems engineering.

How it works

The MPU6050 IMU measures the pitch angle of the system in real time using its onboard Digital Motion Processor (DMP). The Arduino reads this angle and compares it to a target setpoint of 0°.

The controller then calculates an error value:

$\text{Error} = \text{Setpoint} - \text{Measured Angle}$

A PID controller is used to generate corrective motor output:

$\text{Output} = \text{Kp} \cdot \text{Error} + \text{Ki} \cdot \int \text{Error} \cdot \text{dt} + \text{Kd} \cdot \text{d(Error)} / \text{dt}$

Each term serves a different purpose:

  • Proportional (P): Reacts to current tilt error and provides the main corrective force.
  • Integral (I): Corrects long-term offset and steady-state error.
  • Derivative (D): Dampens oscillation by reacting to rapid motion.

The motor outputs are adjusted using PWM signals through IRLZ44N MOSFETs, allowing the system to increase thrust on one side and reduce it on the other to counteract tilt.
